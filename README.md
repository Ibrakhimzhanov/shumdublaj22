# Shum Voice

Настольное приложение озвучки текста голосом на выбор. Работает на API VoiceGen
(`https://qw1voicegencore.pro`).

Стек: Electron + Vite + React 18. Дизайн перенесён из макета
`design/ShumVoice_v2.dc.html` (токены, метрики и тексты один в один).

## Запуск

Установка зависимостей:

```bash
npm install
```

Разработка (Vite с горячей перезагрузкой + Electron):

```bash
npm run dev
```

Собрать и запустить как приложение:

```bash
npm start
```

Собрать установщик для Windows:

```bash
npm run dist
```

Интерфейс можно посмотреть и в обычном браузере: `npx vite`, затем
`http://localhost:5177`. Там вместо настоящего мостика Electron подключается
заглушка `src/dev-mock.js` с готовыми данными (в собранное приложение она не
попадает). Адрес `http://localhost:5177/?login=1` открывает экран входа.

## Как устроено

```
electron/main.cjs      главный процесс: окно, хранение ключа, все HTTP-запросы,
                       скачивание, сборка ZIP, установка обновления
electron/preload.cjs   мостик window.sv (contextIsolation включён)
electron/zip.cjs       минимальный ZIP-писатель без зависимостей
src/App.jsx            состояние приложения, каркас окна, навигация
src/lib/api.js         клиент VoiceGen
src/lib/i18n.js        язык интерфейса, словари лежат рядом с экранами
src/*.i18n.js          строки экранов: { ru: {...}, uz: {...} }
src/lib/models.js      четыре модели синтеза и их параметры (декларативно)
src/lib/audio.js       единый плеер: в приложении играет ровно один источник
src/lib/task.js        настройки озвучки -> поля задачи
src/screens/*.jsx      экраны
```

Ключ доступа хранится только на этом компьютере, зашифрованным через
`safeStorage` Electron, и в веб-слой не передаётся: все запросы к сервису идут
из главного процесса. Поэтому же нет проблем с CORS.

## Что реализовано

| Экран | Состояния |
|---|---|
| Вход | обычное, проверка ключа, ошибка, проверка сохранённого входа |
| Главный | пустой, с текстом, с выбранным файлом, запуск заблокирован (нет голоса / кончились символы / не хватает символов) |
| Задача | идёт, готово с плеером, готово без аудио, частично готово с ошибками, остановлено, потеря связи |
| Библиотека | загрузка, список с бесконечной прокруткой, догрузка, конец списка, ничего не найдено, раздел пуст (три разных текста), ошибка загрузки, окно фильтров, проигрывание образца |
| Клонирование | пусто, файл перетаскивают, файл выбран, идёт создание, ошибка, лимит голосов |
| По описанию | пусто, идёт создание, три варианта, загрузка примера, сохранение, лимит исчерпан |
| Настройки озвучки | обработка текста, свой набор параметров для каждой из четырёх моделей (включая модель без параметров), сохранение |
| Профиль | загрузка, данные, ошибка, переключатели темы и языка |
| Уведомления | четыре типа, стопка |
| Обновление | доступно, скачивание, готово, ошибка |

### Модели синтеза

| В интерфейсе | Движок API | Параметры |
|---|---|---|
| Shum V3 | `elevenLabsV3` | скорость, характер речи (три именованных положения) |
| Aria Pro | `elevenLabs` | скорость, стабильность, похожесть, выразительность, усилитель чёткости |
| Turbo | `fish` | скорость, стабильность |
| Lite | `panda` | параметров нет |

Голос поддерживает не все движки: неподдерживаемая модель остаётся видимой, но
недоступной, с пояснением.

### Слушать раньше, чем всё готово

Общий результат это плейлист из готовых частей. По мере готовности новых частей
список дописывается, а воспроизведение не сбрасывается в начало. Пока задача
идёт, под плеером стоит честная подпись, сколько частей уже доступно. Отдельную
готовую часть можно слушать, не дожидаясь остальных.

## Библиотека голосов

Список грузится порциями по 24 голоса и дописывается по мере прокрутки:
страниц с кнопками «Назад» и «Вперёд» больше нет. Если первая порция не
заполнила экран, следующая подтягивается сразу. Внизу видно, идёт ли догрузка,
и когда голоса по заданному отбору закончились.

Подгрузка считается по самой области прокрутки, а не наблюдателем пересечений:
так она работает и когда окно свёрнуто, и когда система приостановила
перерисовку.

В карточке вместо буквы стоит кружок с плеем: образец слушается прямо оттуда,
играющая карточка обведена золотым, у голоса без образца кнопка видна, но
недоступна. Клик по карточке выбирает голос, двойной клик выбирает и
возвращает к озвучке. Кнопки внутри карточки (плей, звезда, копирование,
переименование, удаление) не задевают выбор.

## Язык интерфейса

Русский и узбекский, переключается в профиле и запоминается на диске. Строки
каждого экрана лежат в файле `ИмяЭкрана.i18n.js` рядом с ним, поэтому экраны
не мешают друг другу. Даты, числа, пол, возраст и языки голоса переводит
`src/lib/format.js`: язык туда ставится один раз из `App.jsx`.

Названия языков в переключателе не переводятся: каждый язык подписан на самом
себе, чтобы человек нашёл свой, не понимая текущего.

## Светлая тема

Палитра светлой темы переработана: золото затемнено до читаемого, границы
усилены, для текста, окрашенного градиентом, заведён отдельный `--grad-text`,
а подсветки активных элементов вынесены в токены `--tint-1/2/3` со своей долей
для каждой темы. Проверено измерением контраста: на всех экранах в обеих темах
нет текста ниже порога WCAG AA (4.5 для обычного, 3.0 для крупного).

## Что стоит знать про сервис

- Серверная очередь может стоять. После создания задачи приложение вызывает
  `POST /api/v1/client/queue/start`. Если у ключа нет свободных runtime-аккаунтов
  (`GET /api/v1/client/runtime` возвращает `accounts: []`), задача честно висит
  в состоянии «в очереди»: это состояние сервиса, а не сбой приложения.
- `thread_count` сервер может уменьшить под тариф, независимо от того, что
  выбрано в настройках.
- Текст ошибки всегда приходит от сервиса и показывается как есть.

## Сборка установщика

```bash
npm run dist
```

На выходе:

- `release/Shum Voice Setup 2.0.0.exe` - установщик NSIS, 78,6 МБ. Ставится на
  текущего пользователя, папку установки можно выбрать.
- `release/win-unpacked/` - распакованная сборка, 273 МБ, запускается без
  установки файлом `Shum Voice.exe`.

Сборка не подписана: сертификата нет, поэтому при первом запуске Windows
SmartScreen покажет предупреждение. Лечится только покупкой сертификата
подписи кода.

Иконка приложения берётся из `assets/mascot.png`. Сейчас там временный знак:
оригинал маскота приехал из дизайн-проекта обрезанным (битый файл лежит в
`design/mascot.truncated.png`). После замены файла нужно положить его и в
`public/mascot.png` и пересобрать.

## Обновление приложения

`GET /api/v1/client/releases/current` это общая лента релизов сервиса, и в ней
лежит установщик другого приложения (VoiceGen). Ставить его вместо себя нельзя,
поэтому окно обновления показывается только для сборок, чьё имя файла
принадлежит этому приложению (`Shum Voice ... Setup.exe`). Когда появится своя
лента релизов, всё заработает само.

## Вход

Логин это и есть API-ключ: отдельных учётных записей у сервиса нет. Приложение
сохраняет ключ и проверяет его запросом `GET /api/v1/client/me` с заголовком
`Authorization: Bearer <ключ>`. Ответ 200 значит вход состоялся, оттуда же
берутся имя, тариф, остаток символов и потолок потоков. Ответ 401 значит ключ
не принят: ключ стирается, показывается текст ошибки от сервиса.

Ключ выпускается на стороне VoiceGen и выдаётся в боте. В OpenAPI сервиса нет
методов регистрации, логина, выдачи или обмена ключа, поэтому приложение может
только принять готовый ключ и проверить его.
